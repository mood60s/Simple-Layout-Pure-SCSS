# Simple-Layout-Pure-SCSS
Responsive multi-section website built with pure HTML5, SCSS, and JavaScript. Features dynamic Arabic/English language switching with real-time content updates, automatic RTL/LTR direction handling, responsive navigation menu, image slider/carousel, reusable UI components, and clean scalable architecture using modular files.
